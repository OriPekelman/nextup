## Imported Claude Cowork project instructions

This is a small web app for running a party where people can contribute things they want to share / show. Poems. Bits of music. Pictures. The basic assumption is that there would be a spotify jam running  (we don't have to interact much with that in v0 - but later it would be cool if we could add music directly to the jam) - people can scan a qr code - or visit a url for the specific party (like nextup.com/wvgd ) and they can: paste a text, upload an image, put a url, put a youtube url ...). They can choose where to put it in the stack of "whats next" - they can't touch the top one - and they can't reorder existing elements - but they can move their proposition anywhere (by default Last In Last out). Then we simply present the thing. There are two interfaces - one for the presentation and one for the upload/stack management. There is no authentication other than the "url being somewhat secret". We have something like nextup.com/wvgd for the upload (we only see things that are programmed as "next" - stuff already shown disappears) nextup.com/wvgd/manage to manage (here things can be deleted/ moved up down - and we can see  stuff that was already shown) and finally nextup.com/wvgd/show (wgvd being a place-holder). on nextup.com/ we can create a new nextup (we don't have a domain name and the name is not final so let's make that configurable). We want to minimize backend services, file-based is fine here. The "show" interface is minimal - no branding etc - we just have a "next/previous" button.  Ask me question if you need to - otherwise one shot this please. You can figure out the missing bits by yourself.
